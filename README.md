# Student Result Management System

A console-based Student Result Management System built with Python and MySQL.

The application allows users to add, search, update, delete, and display student academic records. It automatically calculates total marks, percentage, grade, and pass/fail status.

## Features

- Add student records
- Search students by roll number
- Update student information
- Delete student records
- Display all students
- Automatic total calculation
- Automatic percentage calculation
- Automatic grade calculation
- Pass/Fail result calculation
- Input validation
- Duplicate roll-number prevention
- MySQL database integration
- Environment-variable based database configuration
- Modular project architecture
- Exception handling

## Technology Stack

- Python 3.11+
- MySQL 8.0+
- MySQL Connector/Python
- python-dotenv
- Git
- GitHub
- Visual Studio Code
